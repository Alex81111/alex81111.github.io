Política de Privacidade do ViralMax Cortes

Última atualização: 15 de novembro de 2026.

O ViralMax Cortes é uma ferramenta de uso pessoal que publica cortes de vídeo (Shorts) nos canais do YouTube do próprio dono da ferramenta, como os canais No PeloCast e Universo Paralelo.

1. Uso da API do YouTube

O app usa a API de Dados do YouTube (YouTube Data API v3) apenas para enviar vídeos e publicar comentários nos canais do próprio usuário que autorizou o acesso. O app não acessa canais de outras pessoas.

2. Dados coletados

O app não coleta, não vende e não compartilha dados pessoais com terceiros. Não há anúncios nem rastreamento.

3. Armazenamento dos tokens

Os tokens de acesso concedidos pelo Google ficam guardados apenas no computador do dono da ferramenta e não são enviados a nenhum servidor externo.

4. Como revogar o acesso

Você pode revogar o acesso do app a qualquer momento em https://myaccount.google.com/permissions.

5. Serviços do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado. Ao usar o YouTube, você também concorda com os Termos de Serviço do YouTube e com a Política de Privacidade do Google.
